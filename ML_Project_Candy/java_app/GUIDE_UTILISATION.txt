🚀 ÉTAPE 2 : EXÉCUTION
-----------------------

Depuis Windows (PowerShell) :
   wsl bash run.sh

Depuis WSL :
   cd /mnt/c/Users/remic/Documents/Automatic-Candy-Selector/ML_Project_Candy/java_app
   bash run.sh

Avec une image spécifique en argument :
   bash run.sh ../python_training/datasets/nos_dataset/Test/20260107_143840.jpg


💡 CE QUI SE PASSE
------------------

1. Le programme charge le modèle YOLOv8s entraîné (models/candy_yolov8.onnx)
2. Vous voyez un menu avec 2 options :
   - Option 1 : Choisir parmi les 15 premières images du dossier Test
   - Option 2 : Saisir le chemin complet d'une image
3. Le programme analyse l'image et affiche les bonbons détectés
4. L'image avec les détections est sauvegardée dans detection_result.jpg

❓ DÉPANNAGE
-------------

Erreur "Impossible de charger OpenCV" :
   → Utilisez run.sh au lieu d'appeler java directement
   → Le script configure automatiquement LD_LIBRARY_PATH

Image non trouvée :
   → Vérifiez le chemin avec ls
   → Utilisez des chemins relatifs depuis java_app/

Classes non compilées :
   → Relancez bash compile.sh
   → Vérifiez que lib/opencv-4100.jar existe
