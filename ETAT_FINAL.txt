═══════════════════════════════════════════════════════════════════════
                       🚀 UTILISATION RAPIDE
═══════════════════════════════════════════════════════════════════════

1️⃣  COMPILATION JAVA (une seule fois)
   cd ML_Project_Candy/java_app
   bash compile.sh

2️⃣  EXÉCUTION DÉTECTION
   bash run.sh
   → Menu interactif pour choisir une image
   → Résultat sauvegardé dans detection_result.jpg

3️⃣  ENTRAÎNEMENT PYTHON
   cd ML_Project_Candy/python_training
   python scripts/train_yolov8_candy.py --model m --epochs 100

4️⃣  ANNOTATION INTERACTIVE
   # Sous WSL avec X11 server
   ./check_annotations.bat
   
   # Sous Windows natif
   ./check_annotations_WIN.bat
